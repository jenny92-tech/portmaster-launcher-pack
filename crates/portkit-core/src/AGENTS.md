# 平台解析、文件与传输实现

配置来源选择器验证内嵌或远端根文档，再按检测结果读取具有对应身份和摘要的平台片段。解析器产出路径、能力与环境，文件、下载和健康模块供上层组合使用。

## 约束

- 检测和环境策略只使用有限谓词及字面操作，配置文本不能作为命令执行。
- 远端候选通过完整验证后才可选用；片段身份或摘要不符时保留内嵌回退。
- 持久化修改遵守原子替换与锁边界；下载结果向用户报告路由标识，避免展示内部路由地址。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 共享入口 | `lib.rs` | 暴露核心模块、类型与服务接口 |
| 配置加载 | `config.rs` | 根/平台两层模型、片段读取、解析限制和契约验证 |
| 环境策略 | `environment.rs` | 原生阻止名单、有限字面值操作和子进程环境构造 |
| 错误边界 | `error.rs` | I/O、JSON、配置、解析与环境统一错误类型 |
| 文件基础 | `file.rs` | 文件锁、摘要、ZIP 可读性检查和持久化原子替换 |
| GitHub 传输 | `github.rs` | 能力感知路由、下载进度、超时及镜像/SOCKS 回退 |
| SOCKS 内置名单 | `socks5-tested.txt` | 公开 SOCKS 引导候选；按实际下载目标重新探测，不保证持续可用 |
| 健康检查 | `health.rs` | 有限文件健康规则的校验与损坏诊断 |
| 平台解析 | `platform.rs` | 设备/型号识别、路径策略、能力和托管位置解析 |
| 检测谓词 | `predicate.rs` | 有限检测表达式的递归验证与求值 |
| 配置刷新 | `refresh.rs` | 下载验证后原子刷新配置缓存 |
| 来源选择 | `source.rs` | 按完整性与版本优先规则选择内嵌/远端配置 |
