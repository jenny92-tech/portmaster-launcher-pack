# PortKit 通用核心

> 提供设备配置解析及共享系统基础设施。

## 地位

工作区中可复用的 Rust 核心层，被 APP 业务与服务使用。

## 逻辑

加载两层配置并解析设备、路径、能力和环境；共享下载、文件与健康检查服务支撑上层业务，外部契约测试核对生成配置和 Schema。

## 约束

- 不承载 APP 专属事务或 UI 生命周期，维持数据驱动平台模型。
- 配置、Schema 与所有树内消费者同步更新；版本纪律继承根目录规则。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 共享核心的序列化、网络、摘要和测试依赖 |
| 核心实现 | `src/` | 配置、平台、环境、下载与文件能力，见其 AGENTS.md |
| 契约验证 | `tests/` | Rust 解析器与 JSON Schema 一致性测试，见其 AGENTS.md |
