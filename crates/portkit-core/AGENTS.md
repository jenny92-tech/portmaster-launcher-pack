# 设备配置与通用基础能力

APP 业务层和服务层通过 PortKit 核心读取两层配置，取得设备路径、能力和子进程环境。下载、文件原子操作与健康检查提供共用基础能力，外部测试核对 Rust 解析和配置 Schema 的一致性。

## 约束

- 平台事实通过声明式配置表达，APP 安装事务与 UI 生命周期留在上层。
- 变更配置契约时同步 Schema、生成产物及树内消费者，维持解析结果一致。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 共享核心的序列化、网络、摘要和测试依赖 |
| 核心实现 | `src/` | 配置、平台、环境、下载与文件能力，见其 AGENTS.md |
| 契约验证 | `tests/` | Rust 解析器与 JSON Schema 一致性测试，见其 AGENTS.md |
