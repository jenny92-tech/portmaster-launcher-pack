# 配置契约测试

> 验证生成配置、JSON Schema 和 Rust 解析器保持一致。

## 地位

PortKit 核心的外部契约测试层，直接消费仓库 `config/` 的产物。

## 逻辑

配置行为测试覆盖平台/型号、路径、环境、来源选择与健康规则；Schema 测试以 Draft 2020-12 验证全部平台详情并拒绝非法变体。

## 约束

- 配置事实与解析器必须一起更新，不用放宽测试代替正确实现。
- 文件探测使用构造的上下文或临时目录，非法和未知输入须明确验证拒绝行为。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| Rust 业务契约 | `config_contract.rs` | 配置闭包、设备解析、枚举一致性和安全回退测试 |
| Schema 契约 | `json_schema_contract.rs` | 根/平台文档验证与非法谓词、健康规则拒绝测试 |
