# 配置解析与 Schema 的共同契约

测试直接读取仓库 `config/` 生成产物：Rust 契约用例检查设备、路径、环境、来源选择和健康规则，Draft 2020-12 Schema 用例验证全部平台详情及非法变体。

## 约束

- 平台事实变化需同时反映在解析器和测试中，不能用放宽断言绕过契约不一致。
- 探测使用构造上下文或临时文件；非法、未知输入和安全回退均需明确断言。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| Rust 业务契约 | `config_contract.rs` | 配置闭包、设备解析、枚举一致性和安全回退测试 |
| Schema 契约 | `json_schema_contract.rs` | 根/平台文档验证与非法谓词、健康规则拒绝测试 |
