# 轻量启动辅助实现

> 为 Shell 游戏启动器提供封面、字体和配置等原生文件操作。

## 地位

随每个游戏包分发的 `portkit-launcher` 实现层，不依赖包含 HTTP/TLS 的 `portkit-core`。

## 逻辑

CLI 解析有限子命令并调用库接口；配置编辑、字体供给、封面和增量同步复用本地原子文件工具。

## 约束

- 保持小型本地辅助程序定位，不引入 APP 业务服务或网络依赖树。
- 修改配置须保留未知内容；归档字体提取遵守成员名、格式和大小限制。
- 仅在已验证布局同步前端图片，未知设备不猜测写入位置。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 库入口 | `lib.rs` | 暴露启动辅助功能模块 |
| CLI 入口 | `bin.rs` | 解析参数、分派子命令并报告结果/退出码 |
| 封面同步 | `artwork.rs` | 识别已验证布局并同步启动器图片 |
| 原子文件 | `atomic.rs` | 不引入共享网络核心的持久化写入/复制 |
| 字体供给 | `font.rs` | 复用现有字体或从受限归档提取字体 |
| JSON 编辑 | `json.rs` | 深度合并对象并原子保留未知配置字段 |
| Runtime 选择 | `runtime.rs` | 按自然版本顺序查找最新已安装 LOVE 运行库 |
| 增量同步 | `sync.rs` | 按扩展名和修改时间复制较新资源 |
| Unity 配置 | `unity.rs` | 在指定节更新显示、按键与 GPU 渲染比例 |
