# 随游戏分发的本地启动辅助

Shell 启动器调用此独立 CLI，将封面、字体、结构化配置、运行库选择和资源同步交给原生文件操作。库与命令行共用实现，生成的轻量可执行文件随各游戏包暂存。

## 约束

- 保持独立本地工具边界，不因少量函数复用引入 APP 服务或 PortKit 核心的 HTTP/TLS 依赖树。
- 文件编辑保留无关数据，参数或结构非法时须在替换前失败，避免部分写入。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 库/CLI 入口及归档、序列化依赖声明 |
| 功能实现 | `src/` | 原生启动辅助子命令，见其 AGENTS.md |
| 集成验证 | `tests/` | 配置编辑、同步与命令行拒绝行为，见其 AGENTS.md |
