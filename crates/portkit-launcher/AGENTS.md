# PortKit 游戏启动辅助

> 随游戏包分发的小型本地原生辅助程序。

## 地位

供 Shell 游戏启动器调用的独立 CLI 与库，不依赖 APP Manager 服务或 PortKit 网络核心。

## 逻辑

CLI 将参数交给封面、字体、配置、Runtime 选择与资源同步模块，以本地原子文件操作落地；集成测试覆盖公开命令和库行为。

## 约束

- 保持轻量分发边界，不为复用少量文件函数引入 HTTP/TLS 依赖。
- 文件编辑保留无关数据，非法参数不产生部分写入。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 库/CLI 入口及归档、序列化依赖声明 |
| 功能实现 | `src/` | 原生启动辅助子命令，见其 AGENTS.md |
| 集成验证 | `tests/` | 配置编辑、同步与命令行拒绝行为，见其 AGENTS.md |
