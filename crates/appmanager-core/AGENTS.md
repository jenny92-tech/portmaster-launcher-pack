# APP Manager 核心库

> 提供 APP 专属领域模型、安全文件业务和安装事务。

## 地位

Rust 工作区中的业务层，基于 `portkit-core` 并由 `appmanager-service` 与 LOVE-lite 复用。

## 逻辑

源码将设备解析、资源清单、安装计划、归档事务和 Runtime 修复组合成类型化接口；单元测试与实现同处源码模块。

## 约束

- APP 特定业务留在此 crate，通用配置与 GitHub 字节传输留在 `portkit-core`。
- 保持托管路径、能力限制、文件锁及可恢复事务边界，不执行配置文本。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 业务库元数据及归档/序列化/共享核心依赖 |
| Shell 路径约束 | `SHELL-PATHS.md` | 静态后端的支持范围、安全边界、语料验证与发布限制 |
| 业务实现 | `src/` | 设备上下文、清单和原生事务，见其 AGENTS.md |
