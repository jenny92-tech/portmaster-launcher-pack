# LOVE-lite 运行契约测试

> 以小型 Lua 程序和真实前端验证运行时子集。

## 地位

LOVE-lite 的外部集成测试层，覆盖 API、绘制与原生任务桥接。

## 逻辑

临时 Lua 程序验证基础行为，真实 UIKit、APP 模块和字体验证生产界面；同时检查 GPU 命令与 CPU 回退、脏标志与后台任务交互。

## 约束

- 保留真实前端测试，避免仅用模拟 Lua 掩盖 API 漂移。
- 帧尺寸、字形缓存和重绘调度要覆盖资源边界，退出码必须保持。
