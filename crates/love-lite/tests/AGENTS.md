# LOVE-lite API 与生产界面契约

`runtime_contract.rs` 同时执行小型 Lua 场景和真实 APP 前端，核对 API、字体、绘制、校准与服务任务桥。测试消费共享打包入口，覆盖 GPU 命令、CPU 回退和后台任务触发重绘的关系。

## 约束

- 真实 UIKit、APP 页面和字体必须保留在测试中，不能只靠模拟 Lua 判断兼容。
- 覆盖帧与缓存边界、退出码、320×240 页面可达性，以及弹窗、教程正文和固定操作区的裁切与滚动。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 运行契约 | `runtime_contract.rs` | API、绘制、输入与真实页面集成，包括二维码、完整卸载路径和小屏安全操作 |
