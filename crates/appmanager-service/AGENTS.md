# 嵌入式管理服务

在 `appmanager-core` 之上管理会话、清单快照和后台任务，向 LOVE-lite 及可选 Web 前端提供统一业务入口。设备上下文由配置适配器准备，集成测试通过设备夹具验证公开操作。

## 约束

- 配置事实和事务执行由核心层提供，服务层负责生命周期与调度。
- 后台任务保持互斥、取消和进度语义；Web 会话采用配对鉴权与有界资源管理。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 服务库依赖、序列化和测试配置 |
| 服务实现 | `src/` | 嵌入会话、任务与 Web 管理，见其 AGENTS.md |
| 服务验证 | `tests/` | 设备 profile 下原生/Web 业务端到端测试，见其 AGENTS.md |
