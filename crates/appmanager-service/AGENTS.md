# APP Manager 嵌入服务

> 为 Lua UI 和局域网 UI 提供同一套原生任务服务。

## 地位

连接 `appmanager-core` 与 LOVE-lite 的进程内编排层。

## 逻辑

配置适配器准备设备上下文，会话管理快照与任务，Web 服务在工作线程复用业务入口；集成测试在设备夹具下覆盖公开路径。

## 约束

- 不另建独立配置事实或安装执行器，复用核心领域接口。
- 后台工作保持互斥、取消和进度语义，Web 管理保持配对鉴权与资源限制。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Cargo.toml` | 服务库依赖、序列化和测试配置 |
| 服务实现 | `src/` | 嵌入会话、任务与 Web 管理，见其 AGENTS.md |
| 服务验证 | `tests/` | 设备 profile 下原生/Web 业务端到端测试，见其 AGENTS.md |
