# APP Manager 进程内服务

> 编排原生任务，并向 Lua 和局域网前端提供统一管理会话。

## 地位

位于 UI 运行时与 `appmanager-core` 之间的服务边界，公开嵌入接口而非独立守护进程。

## 逻辑

解析适配器提供设备上下文，launcher 管理会话、清单快照和后台任务；Web 线程复用同一会话，支持设备端开关、配对和安装上传。

## 约束

- 业务写操作由核心层受管路径和能力校验约束；服务保持任务互斥和清单 revision 校验。
- Web 管理必须配对鉴权，并限制请求大小、连接数及上传生命周期。
- UI 使用公开 EmbeddedService 接口，不复制一套配置解析或安装逻辑。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 库入口 | `lib.rs` | 重导出嵌入式服务类型并暴露 Web 端点类型 |
| 会话与任务 | `launcher.rs` | 生命周期、任务分派、清单快照、原生启动和 Web 开关 |
| 编排辅助 | `launcher/` | 活动锁、下载进度和系统探测支持，见其 AGENTS.md |
| 配置适配 | `resolution.rs` | 组装配置路径和设备解析请求 |
| Web 服务 | `web.rs` | 有界 HTTP 处理、配对鉴权、上传安装及管理 API |
| Web 前端 | `web/` | 内嵌浏览器管理单页，见其 AGENTS.md |
