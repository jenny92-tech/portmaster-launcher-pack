# 会话、任务与 Web 编排

解析适配器建立设备上下文，`launcher` 持有管理会话、清单版本和活动任务。Lua 与 Web 使用相同的 EmbeddedService 边界，Web 线程按设备端开关提供配对、上传和管理操作。

## 约束

- 业务写入复用核心层的能力与托管路径校验，任务调度保持互斥并验证清单 revision。
- HTTP 请求、连接和上传生命周期具有独立上限，管理端点始终经过配对鉴权。
- UI 通过公开嵌入接口访问业务；控制器数据库位置由 EmbeddedBootstrap 的同一解析上下文提供。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 库入口 | `lib.rs` | 重导出嵌入式服务类型并暴露 Web 端点类型 |
| 会话与任务 | `launcher.rs` | 生命周期、任务分派、清单快照与扫描诊断日志、原生启动和 Web 开关 |
| 编排辅助 | `launcher/` | 活动锁、下载进度和系统探测支持，见其 AGENTS.md |
| 配置适配 | `resolution.rs` | 组装配置路径和设备解析请求 |
| Web 服务 | `web.rs` | 有界 HTTP、配对鉴权、上传安装及绑定清单 revision 的直接卸载 API |
| Web 前端 | `web/` | 内嵌浏览器管理单页，见其 AGENTS.md |
