# 配对后的浏览器管理界面

`web.rs` 内嵌本目录的单页，浏览器取得配对令牌后读取原生管理快照、上传安装包并提交卸载。页面从配对地址进入时先移除地址栏中的配对码；已有回收内容通过同一服务管理。

## 约束

- 所有管理请求携带会话令牌，能力与权限仍由服务端校验。
- 卸载展示纯文本完整路径，绑定打开清单时的 revision；后台刷新不能替换待确认的 revision。操作区固定可见，默认选择取消。
- HTML 保留 doctype，样式和脚本随页面内嵌；回收站仅在存在旧回收内容时显示。

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 管理单页 | `index.html` | 配对、上传、完整卸载清单、已有回收内容和错误诊断界面 |
