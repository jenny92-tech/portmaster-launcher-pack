# 局域网管理页面

> 提供配对后可操作的安装、已安装项目和回收站界面。

## 地位

由父级 `web.rs` 内嵌提供的浏览器单页资源，复用同一原生管理服务。

## 逻辑

页面从 `/六位配对码` 自动配对或接受手动输入，取得令牌后读取快照并上传安装。卸载前用可滚动清单列出完整路径，绑定打开清单时的 revision，确认后直接删除；仅在有旧回收内容时显示回收站。自动配对先从地址栏移除配对码。

## 约束

- 管理请求携带服务签发的会话令牌；界面展示不代替服务端鉴权与能力校验。
- 保留 HTML doctype；页面样式与 JavaScript 内嵌在当前文件中。
- 删除清单使用纯文本路径，操作按钮固定可见、默认聚焦取消；提交时不能换用后台刷新的 revision。

|------|------------|------|
| 管理单页 | `index.html` | 配对、上传、完整卸载清单、已有回收内容和错误诊断界面 |
