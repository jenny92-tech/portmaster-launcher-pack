# 嵌入服务与 Web 的端到端契约

测试构造设备 profile 和安装包，先通过嵌入接口执行任务并取得清单 revision，再通过 TCP 请求核对 Web 使用相同的设备事实、安装结果和卸载边界。

## 约束

- 设备绝对路径映射到隔离测试根，任何用例都不能依赖真实掌机存储。
- 异步任务等待设置截止时间；卸载等破坏性请求绑定对应清单 revision。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 设备业务验证 | `device_profile_e2e.rs` | 在选定设备 profile 下串联原生任务、包安装、Web 直接卸载及旧回收内容管理 |
