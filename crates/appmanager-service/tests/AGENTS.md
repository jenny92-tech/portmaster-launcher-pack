# 原生服务端到端测试

> 在可控设备目录和配置下验证服务的公开业务路径。

## 地位

位于 `appmanager-service` 的外部集成测试层，同时覆盖嵌入接口与局域网接口。

## 逻辑

构造设备夹具和安装包，通过服务任务取得结果与清单 revision，再以 TCP 请求验证 Web 管理使用相同事实和边界。

## 约束

- 设备绝对路径映射到测试根目录，不能操作真实掌机存储。
- 等待异步任务要有截止时间；破坏性操作必须绑定清单 revision。

|------|------------|------|
| 设备业务验证 | `device_profile_e2e.rs` | 在选定设备 profile 下串联原生任务、包安装与 Web 管理 |
