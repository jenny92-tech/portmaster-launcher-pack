# 应用评估器单元测试

用示例探针文本、临时目录和受控命令验证证据解析与评估编排。测试检查路径白名单、配置绑定及报告内容，无需实际设备运行库。

## 约束

- 端点和采集边界使用合成输入覆盖成功与拒绝路径。
- 报告保持可序列化，并保留失败检查的具体原因。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 证据解析测试 | `test_collect_device_evidence.py` | 端点解析、运行库白名单及启动脚本区段限制 |
| 评估器测试 | `test_pam_lab.py` | 配置绑定、检查日志、摘要与报告 JSON |
