# 管理评估器测试

> 用本地夹具检查设备证据解析和评估报告生成。

## 地位

lab 层不依赖真实设备的 Python 单元测试。

## 逻辑

导入证据解析器与 pam_lab，使用示例文本、临时目录和受控命令校验路径边界、报告绑定及成功/失败结果。

## 约束

- 测试不采集真实设备证据，不要求 SSH/ADB 或设备运行库。
- 运行报告内容保持可序列化，失败信息保留具体检查结果。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 证据解析测试 | `test_collect_device_evidence.py` | 端点解析、运行库白名单及启动脚本区段限制 |
| 评估器测试 | `test_pam_lab.py` | 配置绑定、检查日志、摘要与报告 JSON |
