# 统一作者角标

除 APP Manager 外，现有游戏封面、工具封面、小图和 TrimUI 图标使用同一套紫猫角标。
保留各自原图的尺寸、比例、构图和已有文字，只叠加边框与右下角标，并裁掉圆角外的内容。

APP Manager 的 TrimUI APP 入口使用独立的原始圆角方形图标，保留系统匹配的尺寸与留白；
PortMaster 封面和 APP 内部品牌图使用各自资源。两套入口独立维护，均不叠加本目录的作者边框或右下角标。

| 文件 | 用途 |
|------|------|
| `cat-head.png` | 已确认的紫猫原型，含补齐的左脸毛束和胡须 |
| `corner-overlay.svg` | 自包含的透明图层母版，内嵌猫头、紫色角底和细边框 |
| `corner-overlay.png` | 1024×1024 透明图层，可直接导入图像编辑器 |
| `rounded-mask.svg` | 外轮廓裁切遮罩，白色保留，透明区域删除 |
| `rounded-mask.png` | 1024×1024 裁切遮罩 |

母版画布为 1024×1024，外圆角半径 160，边框宽 8，颜色 `#7950b1`。
猫头等比缩放至宽 168，位于 `(816, 844)`；角底与右边、下边连成整体。
不要给普通游戏添加 APP Manager 专用的金色齿轮或扳手。

处理顺序：原图 → 透明角标图层 → 对合成结果应用圆角遮罩。
透明图层本身不能裁掉原图的方角，必须对最终合成应用遮罩。
制作新图时使用未加角标的原图，避免重复叠加。

正方形图片等比缩放整套母版。横版或竖版图片按短边等比缩放猫头、角底、
边框宽度和圆角半径，将角底锚定右下角，再让边框与遮罩适配整张画布。
不得把正方形母版拉伸为长方形，也不裁切或拉伸游戏原图。

正式封面位于各端口的 `screenshot.png`；小图与 TrimUI 图标沿用各端口现有路径。
打包工具继续读取这些资源，不改变清单字段或版本。
