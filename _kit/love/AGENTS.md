# 共享手柄 UI

> 为普通游戏设置页与 Port App Manager 提供统一的 LÖVE 组件和声明式设置模型。

## 地位

共享工具包的 UI 层，端口通过页面与字段声明复用布局、输入和持久化能力。

## 逻辑

`conf.lua` 配置窗口；`launcher.lua` 将普通端口字段转换为状态、校验和环境输出；`kit.lua` 管理组件、焦点、页面、绘制及状态保存，端口的 `main.lua` 接入生命周期。

## 约束

- 普通启动器使用已安装的 LÖVE，App Manager 使用私有 LOVE-lite；设备环境准备仍在 Shell/Rust 层。
- gptokeyb 是统一手柄输入路径，配置关闭原生 joystick 以免重复响应。
- 状态与环境输出保持原子写入和 Shell 引号转义；失败时不应启动游戏。
- 保留稳定控件 ID 和安全默认动作，不在端口中重写共享输入或渲染系统。
- 焦点先在当前栏内查找，边界再进入同级栏或标题栏；空栏、禁用项及纯展示文本不接收焦点，标题栏下移优先返回原栏。跨栏距离统一使用屏幕坐标。
- 侧栏内部纵向导航使用内容坐标；半宽按钮按同一布局行计数，焦点变化同帧滚入扣除提示条后的可视区。TextView 不添加省略号，超长可见内容慢速滚动；明确分行的地址／配对码优先缩字适配。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| UI 骨架 | `kit.lua` | 控件、页面导航、对话框、布局缓存、绘制与持久化 |
| 容器焦点 | `focus_view.lua` | 基于布局树的组内方向搜索、投影优先和逐级冒泡 |
| 设置声明 | `launcher.lua` | 派生字段默认值、校验、旧设置导入及环境绑定 |
| 窗口配置 | `conf.lua` | 设置全屏窗口与运行模块开关 |
| 按键映射 | `ui.gptk` | 共享 gptokeyb 键盘映射配置 |
| 接口说明 | `README.md` | 组件接口、布局、输入与运行时约束 |
| 背景图片 | `launcher_bg.png` | 共享启动器背景资源 |
