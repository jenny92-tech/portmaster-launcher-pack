# 设置页与 APP 的共享 UI

端口 `main.lua` 将页面、字段和生命周期交给共享层。`launcher.lua` 把游戏声明转换为设置、校验与环境输出；`kit.lua` 维护页面、焦点、滚动和状态；`ui_components.lua` 将这些语义适配到 LUIS，主题与资源模块完成绘制。

## 运行与持久化

- 普通启动器使用已安装 LÖVE，也可复用所选 Unity 运行目录的同套可执行文件与依赖；库路径只在 UI 子进程有效。APP Manager 使用私有 LOVE-lite，设备环境准备留在 Shell/Rust 层。
- 普通启动器关闭原生 joystick，通过 gptokeyb 输入；APP 由 LOVE-lite 直接处理 SDL 控制器。稳定控件 ID、输入与渲染由共享层维护，端口不另写一套。
- 状态与环境输出写到 `love.filesystem.getSource()` 下，使用原子写入与 Shell 引号转义。write/close/rename 或回调失败须阻止游戏启动。

## 游戏设置契约

- Unity 常用页保留渲染、Rudroid 三档内存和可选游戏语言；显示尺寸、画面模式、纹理、帧率、装饰物、效果与按键交换归高级页。渲染跟随已有配置，不能将精确尺寸重置为 100%。
- 后端直接选择 OpenGL ES/Vulkan，仅 GLES 的标题隐藏选择；不增加自动、偏好或当前后端行。可选值受运行库、标题、私有 WSI 与原生预检共同约束；已存无效值显示前归一化，启动前再验证。
- 不适用字段显示“禁用”、置灰并跳过焦点；滤波自动处理，底层效果跟随画面模式，不向玩家提供资源卸载实验项。能力只在启动或选项变化时刷新，不逐帧探测。

## 页面与焦点

- 方向搜索先在当前栏内，再进入同级栏或标题栏；跨栏统一使用屏幕坐标，标题栏下移优先返回原栏。空栏、禁用项和展示文本不接收焦点。
- 子页返回按钮与 B 都沿历史返回并恢复焦点；高级页下的效果、辅助页也遵守此规则。切换 APP 主页清空子页历史。
- APP 主页声明 `root=true,navigation=true`：宽屏左侧导航，小于 600 像素使用单行顶栏与导航菜单。`select_on_focus=true` 使导航焦点切页但留在导航；右键或确认进入内容，普通退出操作不随焦点执行。内容 B 回导航，导航 B 调用 `on_home_cancel`。
- APP 子页保留功能导航，操作放在标题下；旧非导航侧栏仅供通用控件测试。侧栏纵向搜索使用内容坐标，半宽按钮按同一行计数，选中项同帧滚入扣除提示条的可视区；导航放不下时滚动，退出固定底部。
- `inline`/`inline_columns` 组成独立操作行，组首项 `max_width` 限制每项宽度；方向先同行移动，再进入导航。`active` 表示当前分类，`default_focus` 指定内容默认焦点。
- `kit.select(dropdown=true)` 用锚定菜单：A 打开或提交，上下选择，B 取消并恢复焦点；关闭时左右只移动焦点。

## APP 布局与内容

- 页面、确认框和密码键盘统一 A 确认/输入、B 返回；宿主 A/B、X/Y 互换只校正实体识别，不改变界面约定。底部保留相同提示。
- `thumbnail` 读取库存封面且缓存最多 24 张，失败使用功能图标；`library_item` 适配行高，`selection_item` 右侧勾选，`form_field` 按屏宽排列标签和值。Fluent 功能图标不加深色底板，行与控件焦点边框保留。
- `header_toolbar` 固定标题栏操作，`toolbar_row` 独立成行，`toolbar_auto` 按真实字宽决定共用顶行或向右对齐换行；自动栏高 52、字号 20、淡紫底色，数量变化重新测量。按钮徽标垂直居中，`metric` 仅用无底色无图标的大号数值；普通游戏设置不用此 APP 布局。
- 无 `brand_icon` 时大小屏都使用 APP Manager 文字。带 `icon` 的选择器与开关共用列表图标槽和文字起点，按钮、选择器及开关的显式 `height` 使用相同测量与小屏缩放规则。小于 640×480 继续缩放，标题避让开关，页脚按实际换行高度留空。
- `kit.qrcode` 使用离线 L 档、整数模块像素和产品要求的两模块白边；单列页 `fit_available=true` 只占其他行之后的可用空间，地址与底部提示保持可见。长地址由 TextView 完整呈现，明确分行的地址/配对码优先缩字；其他超长内容慢速滚动，不加省略号。
- `row_layout.max_width` 限制阅读宽度，`kit.font` 统一正文测量；`kit.empty` 只显示状态文字，不绘图标或参与焦点。

## 确认框与教程

- 确认框左取消、右确认，默认取消；`single_action` 只保留一个确认按钮，A 确认、B 关闭。`identity` 的图片、名称与制作信息位于正文前，确认问题在正文后，操作区固定。
- `scroll_items` 上下逐项显示完整内容，长路径优先在目录边界换行，溢出滚动；左右选择操作，只显示完整文本行。`item_groups` 使用项目标题与完整路径卡片，上下滚动、L1/R1 翻屏，小屏全屏展示，固定操作区在滚动区之外。
- 标题、密码键盘、进度和底部操作按真实字高留空间。教程使用画布级裁切，不继承页面滚动窗口；正文超高可滚动，按钮始终在正文区外。
