# 共享手柄 UI

共享工具包的 UI 层，端口通过页面与字段声明复用布局、输入和持久化能力。`conf.lua` 配置窗口；`launcher.lua` 将普通端口字段转换为状态、校验和环境输出；`kit.lua` 管理焦点、页面、文本、滚动及状态保存，`ui_components.lua` 连接 LUIS 控件和共享主题，端口的 `main.lua` 接入生命周期。

## 约束

- 普通启动器使用已安装的 LÖVE，可从已选 Unity 运行目录使用同套可执行文件与依赖；库路径仅留在 UI 子进程。App Manager 使用私有 LOVE-lite；设备环境准备仍在 Shell/Rust 层。
- 普通启动器通过 gptokeyb 输入并关闭原生 joystick；App Manager 由 LOVE-lite 直接接收 SDL 控制器输入。
- 状态与环境输出写到 love.filesystem.getSource() 下，保持原子写入和 Shell 引号转义；write/close/rename 或回调失败时不应启动游戏。
- Unity 常用页放渲染和 Rudroid 三档内存，游戏语言可留在常用页；显示尺寸、画面模式、纹理上限、帧率、装饰物、效果与按键交换放高级页。渲染默认跟随配置，不能把已有精确尺寸重置为 100%。
- 子页的返回按钮与取消键都沿导航历史返回上一级，保留原焦点；高级下的效果或辅助页不直接跳回首页。
- 保留稳定控件 ID 和安全默认动作，不在端口中重写共享输入或渲染系统。
- 后端直接选择 OpenGL ES / Vulkan，不设自动、偏好或当前后端行；只有 GLES 的标题隐藏此选择。运行库、标题、私有 WSI 和启动前原生探测共同限制可选值；已存无效值在显示前改为可用默认值，启动前再次校验。不适用项显示“禁用”、置灰并跳过焦点。滤波自动处理，底层效果跟随画面模式；不向玩家暴露资源卸载实验项。只在启动或选项变化时刷新，不逐帧探测。
- 焦点先在当前栏内查找，边界再进入同级栏或标题栏；空栏、禁用项及纯展示文本不接收焦点，标题栏下移优先返回原栏。跨栏距离统一使用屏幕坐标。
- APP 功能主页声明 `root=true,navigation=true`，宽屏显示左侧功能导航；小于 600 像素时使用单行顶栏和导航菜单。导航项用 `select_on_focus=true` 在焦点变化时立即切页，焦点保留在导航中；右键或确认键进入内容，不重复激活页面。B 从内容返回导航，在导航调用 `on_home_cancel`；退出等普通操作不随焦点执行。底部保留默认 A 确认/B 返回提示，切换主页清空子页历史。APP 子页复用同一左侧功能导航，操作固定在标题下方；子页 B 沿历史返回。旧的非导航侧栏仍可用于通用控件测试。
- 内容行可用相同 `inline` 和 `inline_columns` 声明一组筛选或操作按钮，独立成行；该组首项的 `max_width` 限制每项设计宽度，避免单个按钮铺满大屏。方向键先在同行移动，越过边界后再进入导航。`active` 标记当前分类，`default_focus` 指定默认内容焦点。
- `kit.select` 的 `dropdown=true` 使用锚定下拉菜单：A 打开，上下移动选项，A 提交，B 取消并恢复原焦点；关闭时左右键沿布局移动，不直接修改分类。
- `kit.qrcode` 使用离线 L 档编码和整数模块像素，按产品要求使用两模块紧凑白边；单列 APP 页面可用 `fit_available=true` 按其他内容行占用后的剩余宽高放大二维码，地址与底部提示保持可见。长地址仍通过 TextView 完整显示。所有 APP 页面可用 `row_layout.max_width` 限制阅读宽度；`kit.empty` 仅显示状态文字，不绘制占位图标、不参与焦点；`kit.font` 共享正文测量字体。
- `scroll_items` 确认清单用上下键逐项查看完整内容，长路径优先在目录边界换行并在溢出时滚动，左右键选择操作，默认取消。弹窗标题、密码键盘、进度指标及底部操作按真实字高安排，避免小屏重叠。
- APP 列表按钮用 `thumbnail` 读取库存封面（缓存最多 24 张），`library_item` 提供大小屏行高，`selection_item` 使用右侧勾选；`form_field` 按屏宽排列标签和值。`header_toolbar` 把操作固定在标题栏，`toolbar_row` 独立一行；`toolbar_auto` 在标题和完整按钮可同时放下时共用顶行，否则按实际字宽向右对齐换行。自动操作栏使用 52 高、20 字号及淡紫底色；数量改变须同步重测。`metric` 以无底色、无图标的大号数值呈现信息；按钮徽标与整行垂直居中。无效封面回退到功能图标。普通游戏设置页不使用此布局。
- APP 确认框统一左取消、右确认；`single_action` 结果提示仅显示一个确认按钮，A 确认、B 关闭。内容按字高测量，滚动路径只显示完整文本行。
- APP 确认框可通过 `identity` 复用应用图片、名称与制作信息；正文显示在品牌信息之后、确认问题之前，操作区始终固定，长文本换行并滚动。
- 教程浮层使用画布级裁切，不继承页面滚动窗口；卡片按可用高度分配正文区，完整文字超出时滚动，按钮始终在正文之外。
- APP 的页面、确认框和密码键盘始终提示 A 确认/输入、B 返回；A/B、X/Y 互换只校正宿主对实体按键的识别，不改变界面操作约定。
- APP 导航页未提供 `brand_icon` 时，大小屏左上角均使用 APP Manager 纯文字；带 `icon` 的字段选择器和普通开关复用列表按钮的图标槽与文字起点。按钮、下拉选择器和开关的显式 `height` 使用同一测量与小屏缩放规则。
- APP 的功能图标与封面缺失时的回退图标直接显示 Fluent 图形，不加深色圆角底板；行、控件和按钮的焦点边框保留。
- `item_groups` 确认框按项目显示标题和完整路径卡片，上下键滚动整个列表，L1/R1 翻屏；取消在左、卸载在右，固定在滚动区外，默认取消；小屏清单使用全屏。功能导航保持可读行高，放不下时滚动选中项，退出固定底部。
- 侧栏内部纵向导航使用内容坐标；半宽按钮按同一布局行计数，焦点变化同帧滚入扣除提示条后的可视区。TextView 不添加省略号，超长可见内容慢速滚动；明确分行的地址／配对码优先缩字适配。APP 小于 640×480 时继续缩放布局，标题避让开关，侧栏页脚按实际换行高度留空。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 焦点导航依据 | `FOCUS-NAVIGATION.md` | 方向候选、分组、滚动和焦点恢复的设计来源与验收场景 |
| UI 骨架 | `kit.lua` | 控件、页面导航、对话框、布局缓存、绘制与持久化 |
| LUIS 适配 | `ui_components.lua` | 物理像素控件实例、共享绘制和单次语义激活 |
| 统一主题 | `ui_theme.lua` | 按钮、复选框、开关、危险动作及卸载分组卡片的紫猫配色 |
| 功能图标 | `ui_icons.lua` | 按物理像素尺寸读取并缓存官方 Fluent 图集，沿用绘制颜色与既有语义别名 |
| 图标资源 | `icons/` | 固定来源的微软 Fluent filled SVG、抗锯齿图集、布局及 MIT 许可，见子目录 AGENTS.md |
| 二维码视图 | `qr_view.lua` | 延迟编码、矩阵缓存与整数像素静区绘制 |
| 二维码编码 | `qrcode/` | 固定纯 Lua 上游编码器、来源和 BSD 许可 |
| LUIS 源码 | `luis/` | 固定提交的控件子集、直接依赖、来源与许可 |
| 容器焦点 | `focus_view.lua` | 基于布局树的组内方向搜索、投影优先和逐级冒泡 |
| 图形特性 | `graphics.lua` | 运行库/游戏/环境交集、可选后端与字段禁用条件 |
| 设置声明 | `launcher.lua` | 派生显示/渲染/内存等字段、校验、旧设置导入及环境绑定 |
| 窗口配置 | `conf.lua` | 设置全屏窗口与运行模块开关 |
| 按键映射 | `ui.gptk` | 共享 gptokeyb 键盘映射配置 |
| 接口说明 | `README.md` | 组件接口、布局、输入与运行时约束 |
| 背景图片 | `launcher_bg.png` | 共享启动器背景资源 |
