# 私有图形兼容库归档

组包工具从此目录读取经核验的兼容 ELF、加载清单、补丁与来源记录，再按用途暂存到应用私有目录。机型准入和引擎环境预检留在启动适配层，归档校验本身只做静态检查。

## 约束

- 当前归档一份 ARM64 Wayland Vulkan WSI；同一二进制按身份复用，不复制为多个机型版本。完整引擎、系统驱动、玩家资源和用过的运行目录不进入归档。
- 每份记录说明目的、上下游、依赖、范围、接入、失败处理及重编条件，实际 SHA256 与来源 commit、补丁和构建记录共同维护；变更后依据真实构建更新，不能只改校验值。
- 新增板型需独立验证图形路径，低 glibc 要求不能代替设备适用证据。
- `.so` 使用根 Git LFS 规则，实体缺失时恢复对象；指针文本不能当作动态库分发。
- `verify.py` 不加载 ELF、不连接设备或写系统目录；实际加载限制在应用进程。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|---|---|---|
| 存储与接入约定 | `README.md` | 定义归档字段、复用、LFS 和验证方式 |
| 静态归档校验 | `verify.py` | 检查文件闭集校验值、大小、路径与 ARM64 ELF 身份 |
| Wayland Vulkan WSI | `vulkan-wsi-arm64-wayland/` | 已核验的 344 KiB 库、用途文档、来源与分技术栈加载清单 |
