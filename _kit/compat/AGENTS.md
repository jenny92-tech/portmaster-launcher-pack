# 共享图形兼容产物

归档已核验的小型原生兼容库及其加载清单、来源、许可、补丁和 ABI 记录。构建端按需读取；机型准入与引擎预检仍由启动适配层负责。

## 约束

- 当前仅归档一份 ARM64 Wayland Vulkan WSI，不收集完整定制引擎、玩家资源、用过的运行目录、系统 GPU 驱动或凭据。
- 产物按二进制身份复用，不为每个机型复制相同 ELF；新增适用机型需独立记录验证，不能以低 glibc 要求代替图形验证。
- 每份产物说明目的、所处层级、上下游、依赖、适用范围、接入、失败处理和重编条件。来源 commit、补丁、构建记录及实际 SHA256 同时维护。
- `.so` 使用根 Git LFS 规则；缺少实体对象时先恢复 LFS 文件，不将指针文本当成动态库。
- `verify.py` 只静态校验归档，不加载 ELF、不连接设备、不写系统目录。清单选择与启用均限定在应用私有进程内。
- 修改源码、补丁或 ELF 后须经过真实构建和验证再更新记录，不通过修改校验值假称旧产物已重建。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|---|---|---|
| 存储与接入约定 | `README.md` | 定义归档字段、复用、LFS 和验证方式 |
| 静态归档校验 | `verify.py` | 检查文件闭集校验值、大小、路径与 ARM64 ELF 身份 |
| Wayland Vulkan WSI | `vulkan-wsi-arm64-wayland/` | 已核验的 344 KiB 库、用途文档、来源与分技术栈加载清单 |
