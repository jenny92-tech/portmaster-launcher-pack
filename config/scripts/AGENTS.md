# 配置生产工具

> 生成并验证 App Manager 的声明式设备配置契约。

## 地位

配置目录的生产/校验入口，消费 src 片段并输出根配置与平台详情。

## 逻辑

generate.py 拒绝源片段之间重复的顶层键并生成确定性压缩 JSON，将详情散列和字节数绑定到根；validate.py 检查结构、引用、优先级及禁止执行代码的边界。

## 约束

- 生成文件由工具维护，检查已有产物使用 generate.py --check。
- Schema、配置及格式版本遵守根版本纪律，保持当前值。
- Rust 加载器是可执行权威；生产端校验与其约束同步，不另建平台策略。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 配置生成 | `generate.py` | 合并源片段、生成根/平台 JSON 与 --check |
| 结构校验 | `validate.py` | 验证字段、路径、位置角色及已解析设备闭包 |
