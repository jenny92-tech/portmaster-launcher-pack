# 配置生成与验证

`generate.py` 合并源片段并输出确定性 JSON，`validate.py` 验证结构和设备闭包。根文件与平台详情的摘要、字节数共同构成运行时装载输入。

## 约束

- 重复顶层键在合并时拒绝；平台详情变更须同步更新根绑定。
- 字段、引用、优先级和路径角色的生产校验与 Rust 加载器同步，平台策略仍由源片段定义。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 配置生成 | `generate.py` | 合并源片段、生成根/平台 JSON 与 --check |
| 结构校验 | `validate.py` | 验证字段、路径、位置角色及已解析设备闭包 |
