# 配置契约回归

> 验证声明式配置从源片段到生成产物的完整契约。

## 地位

配置生产流水线的 Python 回归入口。

## 逻辑

测试加载正式根与平台 JSON，通过验证器和生成器检查稳定编码、设备选择、安全策略与 Schema 一致性。

## 约束

- 测试直接消费正式配置，反例基于复制的对象或临时文件。
- 不通过放宽验证或版本升级绕过契约失败。
