# 掌机端轻量探针

> 以 POSIX Shell 暴露目标设备能力和受控操作。

## 地位

由主机 Controller 流式传送到 local/Docker/SSH/ADB 目标的 Probe 层。

## 逻辑

探测已安装 provider，返回 TSV 能力清单，再分派有界观测、输入、截图、进程和显式调试命令。

## 约束

- 保持 POSIX sh 与低依赖，不将 APP Manager 业务写入通用 Probe。
- 能力不支持时明确报告，不根据平台名称伪造结果。
- core、trace 和系统日志属于显式操作，不能作为常规诊断隐式执行。

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 探针入口 | `handheld-agent.sh` | 能力发现、设备观测和动作分派 |
