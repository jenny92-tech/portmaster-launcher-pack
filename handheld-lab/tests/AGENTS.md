# 掌机工具验证入口

单元测试以本地 Probe、临时文件和 RecordingTransport 检查 Controller；自测串联语法及本地能力检查，Docker E2E 则验证跨容器输入、事件与截图。

## 约束

- 本地回归和需要设备权限的容器 E2E 独立执行；平台不可用时给出明确跳过原因。
- 场景校验、参数边界和产物路径同时作为验证对象，保留拒绝路径覆盖。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 控制器回归 | `test_handheld_lab.py` | 传输、能力、诊断、场景安全与 CLI 测试 |
| 本地自测 | `run-self-test.sh` | unittest、Python/Shell 检查与本地能力探测 |
| 容器 E2E | `run-docker-e2e.sh` | 跨容器输入、观测、截图和证据验证 |
