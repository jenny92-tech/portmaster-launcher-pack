# 通用掌机工具测试

> 验证控制器、探针和跨目标能力路由。

## 地位

通用设备工具的单元测试与可选 Docker 端到端入口。

## 逻辑

单元测试使用本地 Probe、临时文件和 RecordingTransport；自测串联语法检查；E2E 使用显式目标与 I/O 容器验证真实输入事件及截图。

## 约束

- 本地回归与需设备权限的 Docker E2E 分开执行，Linux 专属观测在其他平台跳过。
- 场景必须先整体校验再执行，测试不能绕过产物路径和参数边界。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 控制器回归 | `test_handheld_lab.py` | 传输、能力、诊断、场景安全与 CLI 测试 |
| 本地自测 | `run-self-test.sh` | unittest、Python/Shell 检查与本地能力探测 |
| 容器 E2E | `run-docker-e2e.sh` | 跨容器输入、观测、截图和证据验证 |
