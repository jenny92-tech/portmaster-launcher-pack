# APP Manager 界面

LOVE-lite 加载 `main.lua` 后，页面请求仅经 `app_native.lua` 进入 Rust 服务；返回的快照和任务事件由 model/operations 更新界面。`app_shell.lua` 拥有各级导航和布局，pages/environment 只组织业务内容，因此权限判断、后台任务与页面呈现分别有明确入口。

## 约束

- 只有 `app_native.lua` 直接跨越 Rust 桥接边界；设备策略和文件操作由原生服务负责。
- 操作确认绑定库存 revision；后台快照不能让旧确认计划作用于新库存。
- 前台任务失败保留原始原因和完整路径，统一详情显示完整日志位置及反馈入口；首页保留失败原因，同类操作成功重试后清除，后台快照不清除。启动失败页保留详情、日志位置与重新加载入口。
- 残留清理列出完整路径，默认取消；确认后直接删除，不移入回收站，也不提示可以恢复。
- UI 使用 Lua 5.1 兼容语法与 kit 控件，保留任务忙碌、取消和退出反馈。各级页面复用 app_shell；功能入口只放导航，当前页面的操作放内容区。空列表隐藏无效操作。
- 已安装首页使用库存中的原封面；分类下拉框靠近标题，刷新、扫描及批量操作统一放标题右侧，用 52 高、20 字号的淡紫色块按钮；空间不足时移到标题下方并靠右换行。分类须在下拉菜单中按 A 提交，B 取消不改变分类。第二个功能导航与对应页面标题统一为“安装游戏”。
- 项目详情的启动/卸载使用并排等宽大按钮，只有一项时占满内容宽度；进入详情默认聚焦启动。显式 `header_toolbar=false` 的行保留内容区布局和尺寸。
- 各级页面由 shell 统一呈现列表、右侧勾选、字段和固定标题操作栏；字段在宽屏左右对齐，小屏及路径上下排列。语言也使用 A 提交、B 取消的下拉框。
- 左上角只显示 APP Manager 文字，不放品牌图；小屏保留相邻的功能切换菜单。设置六项统一 84 设计行高与间距，小屏按同一规则缩放并滚动；图标、文字和右侧控件垂直居中。语言项使用 Fluent 语言图标，A/B、X/Y 互换与按键校准共用手柄图标，图标及文字列与其他设置项对齐。
- 存储可用空间只展示标签与容量，不绘制图标/卡片底、不接收焦点；功能入口右侧的数量与整行垂直居中。
- APP 确认框统一左取消、右确认，默认取消；纯结果提示只留一个确认按钮。校准页沿用共享主题并独立绘制，避免后台页面抢占渲染。
- 按键校准仅在缺少可用映射时自动打开；已有映射的手动校准支持 A+B 或 Start+A 取消且不落盘，不使用任意双键长按触发。
- 设备风险确认使用独立子页，B 或页面返回均回到进入它的 PortMaster/Runtime 页面和原焦点；取消最终确认仍留在风险确认页。
- A/B、X/Y 互换分别存入 UI state，启动和设置变更经 app_native 的 `pam_input_layout` 交给宿主；保存失败回滚。互换用于校正实体按键识别，界面始终提示 A 确认、B 返回。
- 退出是所有功能主页共用的导航底部操作，仅通过确认键激活；返回键依次返回导航、退出确认，子页沿历史返回。
- 退出确认复用关于页的应用图、制作者、反馈群和完整日志路径，信息之后显示退出问题与确定/取消；大小屏保留固定操作区，B 取消并恢复原焦点。
- APP 内部功能图标不画装饰底板；关于和退出使用 `../share/appmanager.png` 的透明紫猫、齿轮与扳手，与外部图片共用原图且不叠加边框角标。行/按钮的焦点框保持可见。
- 运行环境中的 PortMaster 维护、修复游戏 Runtime、环境诊断为并列入口；诊断按游戏影响排序，已关联游戏的 Runtime 异常每项扣 25 分，PortMaster 管理问题每项扣 2 分，正常或未使用的项目不扣分，总分下限为 0。正常项与全部详情均保留；系统托管/定制版身份本身不算问题。PortMaster 不依赖其他页面构建器。
- 远程开启/关闭与扫描操作共用右上角淡紫操作栏；小屏在标题下方靠右显示。二维码按扣除标题、操作栏、地址与底部提示后的剩余宽高取最大整数模块尺寸，二维码与完整地址同屏显示。远程服务仅由当前进程中的显式操作开启，启动和配置重启不恢复上次开启状态。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 应用入口 | `main.lua` | 模块装配、初始快照及任务轮询 |
| 原生边界 | `app_native.lua` | 请求/响应校验、任务事件、输入布局与校准接口 |
| 按键校准 | `app_input.lua` | 控制器示意、步骤高亮、测试与保存覆盖层；经 app_native 获取状态 |
| 共享模型 | `app_model.lua` | 库存/环境状态、失败详情和诊断评分 |
| 操作协调 | `app_operations.lua` | revision 确认计划、取消、任务结果与退出协调 |
| 页面骨架 | `app_shell.lua` | 共用导航、字段布局、标题操作栏和阅读宽度 |
| 业务页面 | `app_pages.lua` | 业务页、关于/退出信息、卸载清单与远程配对 |
| PortMaster 管理 | `app_environment.lua` | PortMaster 状态、修复和设备风险确认 |
| 旧输入映射 | `ui.gptk` | 输入语义参考；当前 SDL 宿主不启动 gptokeyb |
