# APP Manager 启动入口

> 保持原生前端进程关系的轻量 Shell 启动层。

## 地位

APP Manager 发行包的设备入口，由 manifest 指向并随应用 runtime 分发。

## 逻辑

启动器解析包路径、轮转日志并启动 LOVE-lite 子进程；退出码 42 表示读取原生交接文件，然后以选定脚本替换自身。

## 约束

- 保留 POSIX sh 兼容性与所选脚本原始路径、shebang 和工作目录。
- 设备策略留在配置和 Rust crate 中；启动器只承担引导和交接。
- APP 私有 PAM_* 变量不得泄漏到选定应用，游戏输出不得继承管理器日志重定向。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 轻量引导 | `launcher.sh` | 运行 LOVE-lite、轮转诊断日志并执行选定启动项 |
