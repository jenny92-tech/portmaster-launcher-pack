# APP Manager 启动入口

manifest 将此目录的 `launcher.sh` 作为设备入口。Shell 保留前端拥有的父进程，运行 LOVE-lite 并取得退出码；只有退出码 42 才读取服务生成的交接文件，以选定脚本替换自身。日志轮转发生在管理器启动时，游戏交接恢复启动器原有输出描述符。

## 约束

- 保留 POSIX sh 兼容性与所选脚本原始路径、shebang 和工作目录。
- 设备策略留在配置和 Rust crate 中；启动器只承担引导和交接。
- APP 私有 PAM_* 变量不得泄漏到选定应用，游戏输出不得继承管理器日志重定向。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 轻量引导 | `launcher.sh` | 包路径解析 → LOVE-lite 子进程 → 退出码 42 的脚本交接 |
