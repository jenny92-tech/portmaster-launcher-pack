# 空洞骑士：丝之歌端口

启动入口仍为 `Je-空洞骑士_丝之歌[中].sh`。本端口提供启动器与配置适配；
Rudroid、玩家游戏资源和存档单独部署。兼容 `/userdata/silksong`、
`/mnt/UDISK/silksong` 与 PortMaster 游戏目录。

## 设置

| 页面 | 设置 | 新状态默认值 |
| --- | --- | --- |
| 常用 | 渲染分辨率 | 75% |
| 常用 | 内存模式 | 均衡 |
| 高级 | 图形后端 | OpenGL ES |
| 高级 | 显示分辨率 | 自动跟随设备 |
| 高级 | 帧率上限 | 跟随游戏预设 |
| 高级 | 装饰物 | 完整保留 |
| 高级 | A/B、X/Y 交换 | 关 |

已有合法选择保留。渲染可选 100% / 75% / 50%，帧率可选 90 / 60 / 45 / 30 / 25。
内存模式只控制 Rudroid 资源流缓冲及受支持的音频预加载策略，独立于画面和帧率；
不是整个游戏的内存上限，也不承诺切档后提帧。

效果按真机测量设置，不提供低画/原彩、粒子、模糊或光晕开关。
只采用收益明确、画面代价可接受的策略，不额外降低渲染比例、减少装饰物或改动装饰动画策略。
已实测的 TrimUI/A523 固定使用游戏内低柔化档；其余效果沿用设备原配置。
启动时只合并柔化偏好，粒子、语言、音量、存档和其他偏好保持。其他设备不强制这个柔化档。
Vulkan 支持相同渲染比例；目前仅向已登记的 TrimUI/A523、Loong/RK3566 RK817 板路径
开放，按固件名称和完整 device-tree 条目匹配，再检查运行库与原生探测；不按 IP 判断。
未知组合或探测失败时禁用 Vulkan；不可用的后端不能选择，启动时不暗中切换。
TrimUI/A523 的 Vulkan 通过私有 Weston 合成为完整输出尺寸，避开缩小缓冲直接
扫描时的整屏条纹；游戏的渲染比例保持原值。75% 同存档场景与移动已通过实屏核验，
不扩大为旧全特效读档黑屏或全部关卡的验收。所有设备仍默认 OpenGL ES／75%，
通过准入和探测后，可在“高级设置 → 图形后端”手动选择 Vulkan，选择会保存。
私有会话复用系统驱动，不保证 Vulkan 帧率更高或内存更少。

## 配置与交付

UI 状态和环境文件位于实际 `love_ui` 目录。启动器从已确定的绝对 `GAMEDIR`
选择 `config.low.toml`，缺失时使用 `config.toml`；文件名不代表隐藏的低画质档位。
TOML 更改经结构化原子合并，保留包路径、未知配置及用户选择；解析或写入失败停止启动。
不再读取旧的 `SILK_QUALITY` 环境选项。

实验性批量资源卸载固定关闭。菜单退出保留原存档链，只有引擎正常停止且偏好写入成功后
才快速结束进程；快捷键与异常仍走完整清理。游戏阶段不叠加外部按键或强杀器。

执行 `_kit/dist_port.sh silksong`，只部署生成的 `dist/`，保留设备存档、状态与游戏资源。
通用兼容能力属于 Rudroid，游戏专属策略留在本端口及 `game_patches.silksong_unity6`。
