# 丝之歌启动界面

此目录是 SILK_* 设置到游戏 TOML 的转换边界。Lua 声明字段，模板定位既有资源和所选 Rust runtime，准备字体后以 PortKit 原子合并 Unity/GPU/runtime/game patch 配置，最后进入共享 Unity 生命周期。设备专项效果与线程策略集中在模板中。

## 约束

- UI 显示环境仅作用于 LÖVE 子进程；游戏参数和退出清理由共享 Unity 启动链交接。
- 模板必须兼容既有 `/userdata/silksong` 与 `/mnt/UDISK/silksong` 部署路径；游戏目录只需已有资源和选定运行目录中的 Rust loader，不要求保留旧 C loader。
- 优先使用端口包内的 `love_ui`；未安装独立 UI 包时使用游戏目录内的 UI 与 PortKit，保留原设置位置。
- 常用页只放渲染和内存档；帧率、装饰物、显示与按键交换放高级页。效果按实测固定处理，不提供低画/原彩或粒子、模糊、光晕开关；新状态默认完整装饰物；保留各设备现有的效果、装饰动画与驱动配置。
- 新状态默认 OpenGL ES（GLES 3.2）和 75% 渲染；高级页直接选择 OpenGL ES / Vulkan，Vulkan 仅供手动选择，并要求共享层已登记游戏/固件/硬件组合；未知组合直接禁用。原生探测通过不能代表玩法画面正常。保留用户合法选择，已存不可用值在显示前更正；启动后端与所选一致，不适用项显示“禁用”。滤波由程序决定。
- 仅 TrimUI/A523 为私有 Weston 显式要求全尺寸合成，避免缩小的 Vulkan 缓冲直接扫描；预检和游戏使用同一策略，不改 75% 渲染或其他设备的显示路径。
- 模板为丝之歌启用 unity.fast_exit；仅引擎正常请求停止且偏好设置写入成功后快速结束，不在菜单回调或固定超时强杀。
- 仅 TrimUI 且 device-tree 精确为 allwinner,a523 时启用一次性渲染线程分配；Rudroid 再校验在线核容量、原有亲和性与实际呈现线程。没有额外菜单，不联动内存/画质/FPS，不修改系统频率或在线核。
- 同一设备的 Vulkan 路径另启用一次性 FMOD 混音线程分配；切回 GLES 写回关闭。保留原生音频流及 Unity Job 线程策略。
- TrimUI/A523 的实测效果策略只将 ShaderQuality/VidShaderQuality 设为 0；经 PortKit 原子合并，保留其他偏好，解析或写入失败不启动游戏。其他设备不改这些偏好。
- 实验性资源包卸载固定关闭，不设菜单；内存档控制 Rudroid 策略，不表示整个游戏的内存硬上限。帧率写 unity.target_fps，不写 frame_sync_interval_us。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项定义 | `main.lua` | 渲染/内存常用页及帧率、装饰、显示和输入高级字段 |
| 启动模板 | `launcher.sh.template` | 游戏目录选择、原子配置、A523 策略和 Rudroid 启动 |
