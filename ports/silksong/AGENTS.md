# 空洞骑士：丝之歌端口

丝之歌端口负责将显示、帧率、内存和按键偏好写入 Unity 6/Rudroid 配置。`love/` 生成 SILK_* 参数并调用共享 Unity 启动链，manifest 只描述安装身份及运行依赖。运行时和玩家资源由既有游戏安装提供。

## 约束

- 效果采用实测默认策略，不提供低画/原彩或底层效果菜单；保持用户的渲染和内存选择。新状态完整保留装饰物；保留各设备现有的效果、装饰动画与驱动配置。
- 三档内存独立于帧率和画质；实验性标题后卸载固定关闭，不设菜单。Rudroid 自动管理 ELF 文件映射。
- 菜单退出保留游戏原有存档链；引擎停止且偏好写入成功后，由 Rudroid 直接结束进程，避免资源析构等待。快捷键和异常仍走完整清理。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 端口说明 | `README.md` | 设置入口、设备范围和运行限制 |
| 包清单 | `manifest.json` | Unity 运行依赖与安装布局 |
| 封面资源 | `screenshot.png` | 游戏封面原图，用于包预览与同名图片 |
| 启动界面 | `love/` | SILK_* 字段、效果策略和 Rudroid 交接 |
