# 空洞骑士：丝之歌端口

ports/ 下复用 LÖVE 启动界面与 Rudroid/UnityLoader 的游戏端口。manifest 描述包身份、目标入口与运行依赖；love/ 将设置输出为 SILK_* 参数，启动模板再把帧率、渲染比例、按键和内存选项写入 UnityLoader TOML。

## 约束

- 游戏运行时和玩家资源不放进启动器源码目录；本端口只维护设置界面、启动脚本模板和发行元数据。
- 效果采用实测默认策略，不提供低画/原彩或底层效果菜单；保持用户的渲染和内存选择。新状态完整保留装饰物；保留各设备现有的效果、装饰动画与驱动配置。
- 三档内存独立于帧率和画质；实验性标题后卸载固定关闭，不设菜单。Rudroid 自动管理 ELF 文件映射。
- 菜单退出保留游戏原有存档链；引擎停止且偏好写入成功后，由 Rudroid 直接结束进程，避免资源析构等待。快捷键和异常仍走完整清理。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 端口说明 | `README.md` | 菜单入口、低内存设备配置和支持范围 |
| 包清单 | `manifest.json` | 游戏身份、运行依赖、目标路径与图标配置 |
| 封面资源 | `screenshot.png` | 保留游戏封面的原尺寸与构图，使用统一圆角细边框与右下紫猫角底，供包预览及同名图片生成使用 |
| 启动界面 | `love/` | 显示、帧率、内存和按键选项，见子目录 AGENTS.md |
