# 泰拉瑞亚启动界面

泰拉瑞亚移植的 LÖVE 设置层和 Shell 启动模板。模板在检测到 APK 时调用 patcher，Lua 声明 TER_* 选项及资源门禁；设置完成后合并语言 JSON、更新 Unity 配置并复核核心资源。

## 约束

- 本标题固定 GLES，新状态默认 75% 渲染，隐藏不可配置的后端和滤波选项；不适用的可调项显示“禁用”并跳过焦点，输出安全值。
- 渲染分辨率在常用页；输出显示尺寸、A/B 与 X/Y 交换放高级页。常用页三档内存写 Rudroid runtime.memory_mode，默认均衡。
- 核心资源路径必须相对 gamedata/，与 config.toml 和 patch/ 一致。
- 语言配置通过 PortKit JSON 合并保留其他字段，不用文本替换破坏 JSON。
- UI 显示环境不泄漏到游戏；Start 按键和软键盘确认行为按游戏输入契约保留。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项与门禁 | `main.lua` | 声明语言、画面、按键和 APK/核心资源检查 |
| 启动模板 | `launcher.sh.template` | 调用首次解包、应用语言和图形参数并启动游戏 |
