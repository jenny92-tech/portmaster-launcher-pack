# 泰拉瑞亚启动界面

> 提供语言、显示与按键设置，并衔接玩家 APK 首次准备。

## 地位

泰拉瑞亚移植的 LÖVE 设置层和 Shell 启动模板。

## 逻辑

模板在检测到 APK 时调用 patcher，Lua 声明 TER_* 选项及资源门禁；设置完成后合并语言 JSON、更新 Unity 配置并复核核心资源。

## 约束

- 核心资源路径必须相对 gamedata/，与 config.toml 和 patch/ 一致。
- 语言配置通过 PortKit JSON 合并保留其他字段，不用文本替换破坏 JSON。
- UI 显示环境不泄漏到游戏；Start 按键和软键盘确认行为按游戏输入契约保留。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项与门禁 | `main.lua` | 声明语言、画面、按键和 APK/核心资源检查 |
| 启动模板 | `launcher.sh.template` | 调用首次解包、应用语言和图形参数并启动游戏 |
