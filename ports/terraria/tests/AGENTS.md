# 泰拉瑞亚启动契约测试

此脚本读取 main.lua 和 launcher.sh.template，以固定断言核对语言默认值/枚举、TER_* 参数与 PortKit 合并调用，然后执行 Bash 语法检查。它补充共享 Kit 测试，不解包 APK，也不启动 Unity。

## 约束

- 测试只读取源码，不启动设备游戏、解包玩家资源或重建发行包。
- 参数和语言枚举变更时同时维护 Lua、Shell 与这些断言。
