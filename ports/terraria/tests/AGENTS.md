# 泰拉瑞亚启动契约测试

> 静态检查 Lua 选项与 Shell 启动模板之间的语言和共享接口契约。

## 地位

泰拉瑞亚端口专属回归测试，补充仓库通用 `_kit/` 测试。

## 逻辑

检查语言编码、参数名称、JSON 合并与共享函数调用，再执行模板的 bash 语法检查。

## 约束

- 测试只读取源码，不启动设备游戏、解包玩家资源或重建发行包。
- 参数和语言枚举变更时同时维护 Lua、Shell 与这些断言。
