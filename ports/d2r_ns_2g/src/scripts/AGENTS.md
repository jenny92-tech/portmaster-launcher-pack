# D2R NS 2G 打包

D2R_NS_2G_ENTRY 必须显式指定；读取路径赋值，不执行输入或收集其档案。

## 约束

- 保留来源安装的 profile 路径；不得改用其他 D2R 端口的档案。
- 2G 是预设身份，不代表已经完成 2 GB 硬件验收；只接收已准备的匹配 Release runtime。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 标准构建 | `dist-port.sh` | 组装自有 runner、清单、封面和可选安装路径 |
| 路径导入 | `import-entry.py` | 拒绝歧义、命令替换和缺失路径的非执行导入 |
