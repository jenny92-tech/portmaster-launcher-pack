# D2R NS 打包工具

安装路径从显式入口或已有 JSON 导入。构建暂存在 `.scratch/d2r-ns/stage`，完整结果发布到端口 dist。

## 约束

- `D2R_NS_2G_ENTRY` 与 `D2R_NS_2G_PATHS` 互斥；输入按数据校验，保持原 profile 路径。
- 暂存槽原子占用，失败清理；发行内容仅含启动代码、路径清单、封面和许可。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 发行构建 | `dist-port.sh` | 组装启动器并记录包身份 |
| 路径导入 | `import-entry.py` | 解析入口中的字面路径或校验现有 JSON |
