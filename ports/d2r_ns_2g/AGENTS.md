# D2R NS 启动器

NS 94012 的 2G 适配端口。启动器将已准备安装的路径交给运行脚本，游戏资源与引擎由外部 D2R Linux 工程提供。硬件验证范围见 README。

## 约束

- 发行入口为 `Je-暗黑破坏神II_NS（2G版）.sh`，数据目录为 `d2r_ns_2g/`；NS 只维护此发行配置。
- 安装路径作为数据导入，保留原 profile 和资源位置；发行包排除游戏、档案、设备标识及运行状态。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 清单 | `manifest.json` | 端口身份、入口和安装布局 |
| 使用说明 | `README.md` | 资源准备、打包及支持范围 |
| 授权 | `LICENSE` | 启动器、D2R runner 与游戏资源的许可边界 |
| 封面 | `screenshot.png` | D2R 封面与项目图标样式 |
| 启动源码 | `src/` | 安装路径、执行逻辑和打包 |
| 回归测试 | `tests/` | 数据导入、路径验证和预检行为 |
| 忽略规则 | `.gitignore` | 本地组装输出 |
