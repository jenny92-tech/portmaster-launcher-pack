# 空洞骑士启动界面

本目录维护 HKL_* 参数的声明与落盘边界：Lua 只负责设置，模板通过共享辅助程序更新 config.toml、GraphicsSettings 和视频引导 PlayerPrefs，然后调用 Unity 启动器。需要改视频键时，从模板中的定点合并入口开始检查。

## 约束

- 本标题固定 GLES，新状态默认 75% 渲染，隐藏不可配置的后端和滤波选项；不适用的可调项显示“禁用”并跳过焦点，输出安全值。
- 渲染分辨率在常用页；输出显示尺寸、纹理质量、A/B 与 X/Y 交换放高级页。常用页三档内存写 Rudroid runtime.memory_mode，默认均衡。
- 只合并此移植拥有的视频引导和分辨率键，保留玩家语言、音频和其他偏好。
- UI 的显示环境与 Unity 游戏环境隔离；通用运行逻辑交由 `_kit/`。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项定义 | `main.lua` | 分辨率、画质、渲染比例及按键字段 |
| 启动模板 | `launcher.sh.template` | 合并视频键、同步图形设置并交接 Unity |
