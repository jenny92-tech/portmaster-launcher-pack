# 空洞骑士启动界面

> 定义图形和按键选项，并同步游戏视频配置。

## 地位

空洞骑士移植的 LÖVE 设置层与 Unity 启动模板。

## 逻辑

Lua 声明输出 HKL_* 参数；模板更新 config.toml、GraphicsSettings 和所属 PlayerPrefs 视频引导键，再调用共享 Unity 启动器。

## 约束

- 本标题固定 GLES，不显示无意义的后端或滤波选择；不适用的可调项显示“禁用”并跳过焦点，输出安全值。

- 渲染分辨率在常用页；输出显示尺寸、纹理质量、A/B 与 X/Y 交换放高级页。常用页三档内存写 Rudroid runtime.memory_mode，默认均衡。

- 只合并此移植拥有的视频引导和分辨率键，保留玩家语言、音频和其他偏好。
- UI 的显示环境与 Unity 游戏环境隔离；通用运行逻辑交由 `_kit/`。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项定义 | `main.lua` | 声明分辨率、渲染比例、画质和按键配置 |
| 启动模板 | `launcher.sh.template` | 同步图形设置、合并视频引导偏好并启动游戏 |
