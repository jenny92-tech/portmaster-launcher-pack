# 空洞骑士端口

> 提供空洞骑士的掌机启动设置与视频配置适配。

## 地位

ports/ 下复用 LÖVE 启动界面与 Bogodroid UnityLoader 的游戏端口。

## 逻辑

manifest 描述依赖与目标包；love/ 将设置输出为 HKL_* 参数，再同步 Unity 配置、视频设置与必要的 PlayerPrefs 键。

## 约束

- 保存玩家非启动器拥有的偏好；视频引导修复不能覆盖语言或音频设置。
- dist/ 和本机工具缓存属于派生内容，不作为可维护源码导航。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 包清单 | `manifest.json` | 游戏身份、运行依赖、目标路径与图标配置 |
| 使用说明 | `README.md` | 端口部署与运行说明 |
| 授权 | `LICENSE` | 端口授权声明 |
| 预览图 | `screenshot.png` | 发行包游戏截图 |
| 启动界面 | `love/` | 图形/按键选项及 Unity 视频配置同步，见子目录 AGENTS.md |
