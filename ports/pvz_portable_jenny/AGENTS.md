# PvZ Portable 维护版

只维护启动和发行层，原生游戏工程在相邻 PvZ-Portable。

## 约束

- 普通目录与档案路径不改名，SH 使用 Je- 前缀。
- 不打包 main.pak、properties、userdata、注册信息、缓存和玩家设置。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 清单 | `manifest.json` | 独立入口和无游戏资源的安装说明 |
| 说明 | `README.md` | 引擎来源、构建与玩家资源准备 |
| 授权 | `LICENSE` | 启动器、引擎和游戏资源边界 |
| 源码 | `src/` | 设备入口及固定清单打包 |
| 忽略规则 | `.gitignore` | 生成的 dist |
