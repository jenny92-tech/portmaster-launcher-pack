# 像素黑神话端口

> 以 Bogodroid 运行像素黑神话，并提供游戏专属设置界面。

## 地位

ports/ 下使用通用 LÖVE UI 与 UnityLoader 的 Unity IL2CPP 游戏端口。

## 逻辑

manifest 描述包与运行依赖；love/ 输出启动参数并调整游戏图形、输入和辅助配置，共享 `_kit/` 完成打包及设备适配。

## 约束

- 游戏特定 IL2CPP 配置仅在 love/ 模板维护；通用启动能力复用 `_kit/`。
- dist/ 为生成产物，不在其中修改启动逻辑或初始化源码文档。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 包清单 | `manifest.json` | 游戏包身份、依赖、设备与预览图配置 |
| 使用说明 | `README.md` | 部署与运行文档 |
| 授权 | `LICENSE` | 端口授权声明 |
| 预览图 | `screenshot.png` | 发行包游戏截图 |
| 启动界面 | `love/` | 游戏选项、辅助配置和启动模板，见子目录 AGENTS.md |
