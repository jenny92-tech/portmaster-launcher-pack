# 像素黑神话启动界面

> 定义画面、按键和游戏辅助选项，并应用到 Unity 运行配置。

## 地位

像素黑神话移植的设置界面与 Shell 启动模板，依赖 `_kit/` 共享 LÖVE/Unity 适配层。

## 逻辑

`main.lua` 声明页面并输出 HSH_* 参数；Shell 模板应用画质、按键、触屏布局与 IL2CPP 辅助配置，然后启动 Unity。

## 约束

- 本标题固定 GLES，不显示无意义的后端或滤波选择；不适用的可调项显示“禁用”并跳过焦点，输出安全值。

- 渲染分辨率在常用页；输出显示尺寸、纹理质量、A/B 与 X/Y 交换和辅助页入口放高级页。常用页三档内存写 Rudroid runtime.memory_mode，默认均衡。

- 界面阶段的显示环境必须留在共享 UI 子进程中，不得污染游戏阶段。
- 通用显示、按键和进程管理逻辑留在 `_kit/`，本目录仅维护游戏差异。
- 辅助配置中的类、方法和字段偏移与目标游戏版本耦合，不能仅按名称推测调整。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项定义 | `main.lua` | 声明图形、按键和辅助页面及 HSH_* 参数 |
| 启动模板 | `launcher.sh.template` | 将选项写入 Unity 配置并运行游戏 |
| 游戏输入映射 | `heishenhua.gptk` | 保存像素黑神话的 gptokeyb 按键映射 |
