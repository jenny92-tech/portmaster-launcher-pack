# 像素黑神话启动界面

`main.lua` 把图形、按键和辅助页面声明交给共享 launcher，并输出 HSH_* 环境参数。`launcher.sh.template` 消费这些值，应用画质、触屏布局和 IL2CPP 辅助配置，再调用共享 Unity 生命周期；引擎加载逻辑不在此实现。

## 约束

- 本标题固定 GLES，新状态默认 75% 渲染，隐藏不可配置的后端和滤波选项；不适用的可调项显示“禁用”并跳过焦点，输出安全值。
- 渲染分辨率在常用页；输出显示尺寸、纹理质量、A/B 与 X/Y 交换和辅助页入口放高级页。常用页三档内存写 Rudroid runtime.memory_mode，默认均衡。
- 界面阶段的显示环境必须留在共享 UI 子进程中，不得污染游戏阶段。
- 辅助配置中的类、方法和字段偏移与目标游戏版本耦合，不能仅按名称推测调整。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项定义 | `main.lua` | HSH_* 字段、页面和可调项约束 |
| 启动模板 | `launcher.sh.template` | 按类型更新 Unity/辅助配置后启动 |
| 游戏输入映射 | `heishenhua.gptk` | 本标题的 gptokeyb 动作映射 |
