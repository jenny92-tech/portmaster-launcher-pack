# Je-Wine

独立应用；不接入 Unity/Rudroid 原生加载链。共用运行器识别机型及其环境，再将每个游戏声明的 API 解析为公共组件。运行器、共享组件、游戏适配和电脑准备工具分别构建。

## 约束

- 当前硬件记录只有 LoongOS 1.4.0.36 迷你龙，其他固件不按芯片相似性默认支持。
- 游戏适配不能包含机型路径、GPU 实现或公共运行库。
- 运行器和游戏发行包解压到 SD 卡根目录；带身份清单的标准离线环境 ZIP 可直接放在卡根目录识别导入。规范游戏库为 roms/windows，运行器/环境在 .winecellar，资源在各游戏 data，Ports 只放首页桥接。
- 运行器自带固定校验的私有 Python/字体/输入启动环境，不要求系统 Python 或 PortMaster；游戏适配 ZIP 不含游戏或公共运行库。
- 输入优先复用已安装 PortMaster 的映射和完整工具对，工具不可用时回退随包版本；路径属于机型层，游戏只声明键鼠动作。
- 不分发用过的 runtime.ext4、prefix、测试日志、缓存、玩家存档或处理后的游戏副本。
- 安装器目前只通过本地验证，尚未完成设备验收。
- 只操作私有目录、映像和会话，不停止固件服务，不暴露 winecfg。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 包清单 | `manifest.json` | 独立 Ports 应用声明与支持范围 |
| 运行器与分层定义 | `src/` | 安装、会话、配置继承、游戏准备和独立打包 |
| 来源基线 | `runtime-sources.json` | 固定上游 revision、校验和本地构建身份 |
| 启动环境来源 | `bootstrap-sources.json` | 固定私有 Python、输入工具、字体/数据库来源与校验 |
| WSI 补丁 | `wsi-ext-timestamps.patch` | 厂商 Mali 时间戳扩展适配 |
| 使用与构建 | `README.md` | 分层边界、离线/HTTPS 安装、补资源及验证范围 |
| 授权 | `LICENSE` | 运行器授权与独立组件授权边界 |
| 界面记录 | `screenshot.png` | 保留原运行器截图尺寸与构图，使用统一圆角细边框与右下紫猫角底 |
