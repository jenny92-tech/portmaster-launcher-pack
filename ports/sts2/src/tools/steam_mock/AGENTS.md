# Steam 接口桩生成

gen_stubs.py 扫描外部 gbe_fork 的 flat.cpp/dll.cpp，提取指定 Steam 导出前缀并去重，再以返回类型表和 OVERRIDES 生成 C 桩。产物供 ARM64 离线链接使用，不连接或实现 Steam 服务。

## 约束

- 返回类型决定调用 ABI；修改类型表或覆盖时须核对目标包装器的调用约定。
- 共用的非空接口地址只满足空值检查，不提供虚函数表，不能用于直接虚调用。
- 生成 C 和库由生成器维护；不能将可链接等同于 Steam 功能可用。
