# STS2 静态资源覆盖

上级 apply.sh/build.sh 通过 rsync 将此树复制到恢复工程和覆盖目录，再交给 PCK 写入器。目录相对路径就是游戏 res:// 路径；这里保存可维护静态输入，不是引擎生成的导入缓存。

## 约束

- 复制范围包含本树全部文件和导航文档，文档修改也会改变重新生成的覆盖负载。
- 保持游戏引用的脚本基类与扩展资源路径；外部动态库不由此树隐式补齐。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| addons | `addons/` | 原 addons 路径下的架构映射与无原生 SDK 占位脚本 |
