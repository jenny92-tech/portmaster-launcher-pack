# 离线程序集实验工具

> 汇集针对 STS2 启动链路的 Mono.Cecil 修改脚本。

## 地位

移植工具中的离线 DLL 调试分支，与运行时 Harmony 补丁并存。

## 逻辑

scripts 读取游戏程序集、修改指定 IL 并写入调用者指定输出，分别处理预加载、WorldEnvironment 和启动跟踪。

## 约束

- 输入游戏程序集由玩家提供，不纳入源码或分发。
- 脚本运行会改写输出 DLL，不为文档验证执行。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| scripts | `scripts/` | 针对启动预加载、无 3D 环境和追踪的 C# 脚本 |
