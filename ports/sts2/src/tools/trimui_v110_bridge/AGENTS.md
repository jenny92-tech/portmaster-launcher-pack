# STS2 TrimUI 0.110.1 桥接

本工具针对固定 SHA 的 0.110.1 compat DLL，把 SDL Godot fork 的早期 ModEntry.Apply 回调改为 NOP/RET，让初始化继续由游戏侧入口负责。它读取程序集并生成新 DLL，不重编引擎，也不执行游戏代码。

输入必须匹配固定摘要；输出须是尚不存在的独立路径。写后检查程序集名、方法集合、其他方法指令和嵌入资源 SHA，任何无关变化都会拒绝发布。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 构建声明 | `Bridge.csproj` | 显式 Mono.Cecil 路径及桥接工具构建 |
| 程序集改写 | `Program.cs` | 固定输入、回调结构校验、单方法改写与完整读回 |
