# 托管入口探针

> 在独立 .NET 控制台程序中复现游戏程序集解析。

## 地位

ARM64 移植工具中的运行时初始化故障诊断入口。

## 逻辑

从程序目录解析依赖并载入 sts2.dll，查找 GodotPlugins 初始化方法并记录签名、属性和调用准备结果。

## 约束

- 目标运行时为 linux-arm64 自包含 .NET；运行时版本与设备一致。
- 实际探测依赖玩家程序集，不将游戏 DLL 提交到仓库。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| Program.cs | `Program.cs` | 复现 Godot 托管程序集解析环境以诊断初始化入口加载 |
| probe.csproj | `probe.csproj` | 探针的目标框架、运行时和自包含构建配置 |
