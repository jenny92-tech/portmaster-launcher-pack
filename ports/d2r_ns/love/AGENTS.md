# D2R NS 启动界面

复用 `_kit/love` 的开始/退出与署名页面，模板加载标准 PortMaster、安装私有执行文件并交接已验证游戏预设。

## 约束

- 不暴露未实现的 Unity 内存、图形后端或分辨率选项。
- UI 环境与输入映射随 UI 子进程退出；游戏保留自己的原生手柄路径。
- `--check` 只检查安装和路径，不运行 UI、游戏、调频或挂载。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 页面 | `main.lua` | 声明开始、退出和作者署名 |
| 启动模板 | `launcher.sh.template` | 包目录发现、私有执行文件安装、UI 与游戏生命周期 |
