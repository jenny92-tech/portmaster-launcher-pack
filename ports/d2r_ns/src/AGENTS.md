# NS 运行与资源安装

安装器把执行程序、原生模块和 PortKit 放到内部执行目录，新存档放独立的内部档案目录；大体积资源留在包目录。`run-game.sh` 保留已验证运行参数，`scripts/` 负责公开启动器与私人完整资源包。

## 约束

- 安装必须校验内容散列并原子发布；保留已有设置和角色，不复制来源设备档案。
- `run-game.sh` 由已验收入口移植，改变路径时不顺带改画质、内存、图形或时钟策略。
- 游戏阶段不重新加载 UI 映射，不使用宽泛进程清理。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 安装 | `setup_runtime.py` | 校验并准备私有执行目录、幂等创建干净默认设置 |
| UI 安装 | `setup_ui_runtime.py` | 把已安装 PortMaster 的 LÖVE/输入程序校验缓存到内部执行目录 |
| 预设 | `default-settings.json` | 固定画质与中文默认值，无角色或玩家进度 |
| 游戏执行 | `run-game.sh` | 已验证 NS 94012 参数、会话锁和退出恢复 |
| 运行时授权 | `licenses/` | D2R Linux 与其解码/接口依赖的独立许可 |
| 构建 | `scripts/` | 生成启动器、合并生效资源和创建加密完整包 |
