# 龙沉异世录资源准备

最小包的启动模板调用 setup-gamedata.sh，将只读 Windows GameData 和预置 ARM64 核心组合成运行资源树。脚本先校验输入，再暂存可复用资源、替换目标树并准备 conf/il2cpp；就绪标记是最后的成功信号。

## 约束

- `GameData/` 是玩家只读输入，不能改名或删除其中原始文件。
- ARM64 libil2cpp 与生成的元数据必须匹配；Windows DLL 不进入运行树。
- 只有最终核心文件校验通过后才能写就绪标记；缺资源或准备失败不能被标记为可启动。
