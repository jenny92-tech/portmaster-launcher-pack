# 龙沉异世录资源准备

> 将玩家 Windows 资源与预置 ARM64 核心组合成 Android 运行布局。

## 地位

最小包首次启动的数据准备层，由 Shell 启动模板按需调用。

## 逻辑

校验 Windows 游戏与预置核心文件，暂存可复用资源，替换运行资源树，准备 conf/il2cpp，最后写入就绪标记。

## 约束

- `GameData/` 是玩家只读输入，不能改名或删除其中原始文件。
- ARM64 libil2cpp 与生成的元数据必须匹配；Windows DLL 不进入运行树。
- 就绪标记必须在最终核心文件校验后才代表准备成功。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 资源准备脚本 | `setup-gamedata.sh` | 校验玩家副本并组装运行资源与 IL2CPP 外部资源 |
