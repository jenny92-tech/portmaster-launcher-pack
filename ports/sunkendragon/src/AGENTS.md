# 龙沉异世录开发流程

> 汇集消费 Bogodroid 构建结果的包组装入口。

## 地位

龙沉异世录开发侧流程导航，设备入口和资源转换分别位于 love/ 与 patch/。

## 逻辑

scripts/ 根据完整 Android 基线或最小核心模式暂存 runtime、配置和资源准备脚本。

## 约束

- 此目录不构建 Unity 游戏源码，只消费外部转换和 runtime 构建产物。
- 不将生成 dist/ 当作可维护源码，变更应落在模板或组装脚本。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 包组装 | `scripts/` | 完整基线和最小包流程，见子目录 AGENTS.md |
