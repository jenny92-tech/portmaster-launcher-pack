# 龙沉异世录开发流程

此目录为两种开发装配模式提供入口：完整 Android 基线，或要求玩家补充 Windows GameData 的最小核心包。scripts 消费外部 Bogodroid/转换产物并生成发行负载；设备启动和资源迁移仍分别由 love 与 patch 承担。

## 约束

- 此目录不构建 Unity 游戏源码，只消费外部转换和 runtime 构建产物。
- 不将生成 dist/ 当作可维护源码，变更应落在模板或组装脚本。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 包组装 | `scripts/` | 按模式选择完整 payload 或最小 ARM64 核心 |
