# 龙沉异世录启动界面

Shell 模板在进入 LÖVE 前按需调用资源准备脚本；Lua 用同一核心文件布局决定能否启动，并输出 SDR_* 设置。参数应用完成后才交给共享 Unity 链，因此资源失败应留在设置/引导层，不进入引擎。

## 约束

- 渲染分辨率在常用页；输出显示尺寸、A/B 与 X/Y 交换放高级页。本实验性端口尚不提供 Rudroid 内存模式。
- Lua 与 Shell 的核心文件检查必须对应同一 gamefiles 布局。
- 缺少玩家资源时保留界面引导，不将资源准备失败静默视为可启动。
- 共享显示和 Unity 生命周期留在 `_kit/`，原生库路径只补充游戏实际依赖。

## 业务域清单

| 名称 | 文件/子目录 | 职责 |
|------|------------|------|
| 选项与门禁 | `main.lua` | SDR_* 字段及核心资源就绪判断 |
| 启动模板 | `launcher.sh.template` | 资源准备、设置应用和 Unity 交接 |
